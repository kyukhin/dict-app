# Fixture: ell-unknown-tense

A short rule: *σπίτι* is a house.

```forms
words: γράφω
tense: aorist
```

## Examples

- Το σπίτι είναι μεγάλο.
  The house is big.
- Έγραψα ένα γράμμα.
  I wrote a letter.
- Βλέπω το σπίτι.
  I see the house.
