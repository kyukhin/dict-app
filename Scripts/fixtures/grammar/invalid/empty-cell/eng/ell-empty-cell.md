# Fixture: ell-empty-cell

A short rule: *σπίτι* is a house.

```forms
words: έχω
tense: aorist
```

## Examples

- Το σπίτι είναι μεγάλο.
  The house is big.
- Έγραψα ένα γράμμα.
  I wrote a letter.
- Βλέπω το σπίτι.
  I see the house.
