# Проверка: ell-translation-script

Короткое правило: *σπίτι* значит «дом».

| | Единственное число |
|---|---|
| Именительный | το σπίτι |

## Examples

- Το σπίτι είναι μεγάλο.
  The house is big.
- Έγραψα ένα γράμμα.
  Я написал письмо.
- Βλέπω το σπίτι.
  Я вижу дом.
