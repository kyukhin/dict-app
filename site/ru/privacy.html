Политика конфиденциальности

Последнее обновление: 2026-11-09

Что собирает приложение

Ничего. В приложении нет аналитики, рекламы, аккаунтов и идентификаторов. История, «Мои слова», прогресс обучения и статистика хранятся только на вашем устройстве.

Загрузка языков

Когда вы просите скачать язык, приложение загружает общедоступные файлы с GitHub Releases. Как при любой загрузке, GitHub получает ваш IP-адрес и системный user agent в соответствии с политикой конфиденциальности GitHub. LibreDict не получает ничего, что вас идентифицирует.

Сообщить об ошибке

Только если вы нажмёте эту кнопку. Приложение «Почта» покажет всё письмо целиком, включая версии приложения и iOS, до отправки.

Ежедневное напоминание

Напоминание — локальное уведомление на вашем устройстве. Ничего не отправляется на сервер.

Этот сайт

Он не ставит cookie, ничего не загружает с других серверов и не считает посещения.
